Grounding

"Just connect it to ground" is where most PCB problems begin. Ground is not a magic sink — it is a conductor with real resistance, real inductance, and real current flowing through it.

What Ground Actually Is

Ground is the voltage reference for a circuit — the common return path that all signals and supplies are measured against. It is defined as 0 V by convention, not physics.

On a real PCB, ground is a network of copper traces, pours, and vias. It has finite impedance. Any current flowing through that impedance creates a voltage drop — which means two "ground" points on a board are often at different potentials.

V_noise = I_return × Z_ground

Z_ground = R + jωL. At DC, resistance dominates. At high frequency, inductance dominates.

Types of Ground

TypeDescriptionUse case
Signal GND Return path for logic and low-level signals MCU, sensors, communication lines
Power GND Return path for high-current loads Motor drivers, power converters
Analog GND (AGND) Quiet reference for ADC and precision circuits ADC reference, opamp supply return
Chassis / Earth GND Connected to metalwork and safety earth Safety, shielding, ESD path

Ground Plane

A solid ground plane (a full copper layer dedicated to GND) is the single best thing you can do for signal integrity and EMI on a PCB. It provides:

  • Low impedance return path for all signals
  • Controlled impedance for transmission lines
  • Natural return current path directly beneath signal traces
  • Thermal spreading
Practical tip On a 2-layer board: dedicate the bottom layer to ground as a solid pour. Route power and signals on the top. Avoid splitting the ground plane — slots and gaps in the plane force return currents to detour, creating noise loops and EMI.

Star Grounding vs. Ground Plane

Star ground: All subsystems connect to a single central ground point. Prevents high-current paths from contaminating sensitive circuits. Used in audio, precision analog.

Ground plane: Solid copper layer shared by all circuits. Lower impedance, better for digital and mixed-signal boards. Return currents follow the path of least impedance, which at high frequency is directly beneath the signal trace.

Practical tip For mixed-signal boards: use a single ground plane (do not split it). Instead, carefully manage the layout — place analog circuitry in one region, digital in another, and route the high-current power return traces away from sensitive analog areas.

Common Grounding Mistakes

  • Ground loops: Multiple ground connections between systems at different potentials create circulating currents — a major noise source in analog and audio circuits.
  • Shared return paths: Routing motor or switching converter return currents through the same ground trace as sensor signals injects noise directly into your measurements.
  • Long ground traces: Inductance increases with length. At switching frequencies (100 kHz+), even a few nH matters. Keep decoupling capacitor ground connections short.
  • Missing ground pour connection: A via that is surrounded by a ground pour but not connected to it (no thermal relief, no connection) is an open circuit.
