Hardware Design Checklists

Schematic Checklist

  • All ICs have decoupling capacitors
  • Unused MCU pins handled correctly
  • Pull-ups and pull-downs added where required
  • Protection circuitry reviewed
  • Power rails verified

PCB Checklist

  • Ground plane present
  • Return current paths verified
  • Trace widths checked
  • Via sizes verified
  • DRC passes without errors

Manufacturing Checklist

  • Silkscreen reviewed
  • Assembly clearances checked
  • Test points added
  • Gerbers generated and verified
